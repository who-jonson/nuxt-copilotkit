---
title: Frontend tools
description: "Register browser functions as frontend tools that the AI model can call during conversations."
navigation:
  icon: i-lucide-wrench
---

The `@copilotkit/vue` v2 composables are auto-imported; see [Composables](/api/composables) for the full list. Register a tool with `useFrontendTool`:

```vue
<script setup lang="ts">
useFrontendTool({
  name: 'sayHello',
  description: 'Say hello to the user',
  handler: async ({ name }: { name: string }) => `Hello, ${name}!`
})
</script>
```

The same composables can be imported explicitly from `#copilotkit`:

```ts
import { useFrontendTool } from '#copilotkit'
```

See [Composables](/api/composables) for the full list, and the [CopilotKit docs](https://docs.copilotkit.ai/vue) for each composable's options.
